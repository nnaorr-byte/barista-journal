# נכסי האייקון

`icon-master.png` — המקור (1254×1254, RGB). כל האייקונים ב-`public/` נגזרים ממנו.

הצורה הכהה בתוך המקור יושבת ב-`(80, 48)` בגודל `1093×1135`, עם רדיוס פינה
של ~256px. סביבה יש לבן וצל רך — **שניהם חייבים להיחתך**: iOS מוסיף מסכת
squircle משלו, ופינות שכבר עוגלו בקובץ נחתכות פעמיים ומשאירות תפר בהיר.

## הפקה מחדש

הצינור: חיתוך לצורה → מסכת ריבוע-מעוגל ברדיוס גדול ב-6px מהמקור (כדי
שטבעת ה-anti-alias הלבנה לא תדלוף) → מירכוז על ריבוע מלא בצבע `#19130d`
→ הקטנה ב-LANCZOS.

| קובץ | גודל | הערה |
|---|---|---|
| `public/apple-touch-icon.png` | 180×180 | **RGB מלא, לא פלטה** — האייקון שמערכת ההפעלה של האייפון קוראת |
| `public/icon-192.png` | 192×192 | favicon + manifest |
| `public/icon-512.png` | 512×512 | manifest, `purpose: any` |
| `public/icon-maskable-512.png` | 512×512 | manifest, `purpose: maskable` — האיור מוקטן ל-80% כי אנדרואיד חותך |

השלושה האחרונים מקוונטזים ל-256 צבעים (חוסך ~50% בלי הבדל נראה בגודל
אייקון). ה-512 מוחרגים מהמטמון המקדים ב-`vite.config.ts` — הם נקראים רק
ברגע ההתקנה, מהרשת.
